# 一覧3形式の比較サンプル（Issue #44）

## 採用する配置と残る仮動作

現在の小型は通常幅1024pxで横5件、中央画像140×187px、タイトル17px最大3行、タイトル下に高さ28pxの横長「⋯」を置く。行・カードは40×40pxの「⋯」。行は交互背景、全形式にホバー/枠内フォーカス強調を付ける。上部の操作は2行。製品画面は未変更である。

形式切替で検索を維持して先頭/1ページ目へ戻る方針は承認済み。ページ切替は#44の後の別Issueとし、小型24件・行20件・カード12件は仮案のまま。検索時のページリセットや多数ページの番号表示等は製品仕様として未確定。

サンプルは配置確認用のネイティブdetailsを使い、製品で必要な「メニュー同時に1つ・Esc/外クリック/形式切替で閉じる・フォーカス復帰」を実装検証したとは扱わない。通知の引継ぎ、設定保存・復元、実WebView2での動作も未検証。サンプルの起動・登録・メニュー項目はデータを変更しない。

`node tools/mockups/library-layout/sample.test.cjs`で、合成DOM境界による描画文字列・仮ページ件数/境界/0件・列指定・不正パラメーター初期値を確認する。これはCSSの実寸・レイアウト・実ブラウザー操作のテストではない。

## 比較途中の記録（以下の「最新」「未確定」は当時の記録）

配置の比較履歴を以下に残す。現在の採用案は上節と設計正本を参照し、途中案を現行仕様と扱わない。

利用者の指定により、最新の小型案は中央画像・タイトル最大3行・高さ28pxの横長「⋯」の順とする。ボタンをタイトルの下へ移し、画像・タイトル・ボタンの寸法と枠全体の高さは直前の案から変えない。

最新の小型比較案は、中央画像・高さ28pxの横長「⋯」・タイトル最大3行の順。操作ボタンを枠内の横幅いっぱいにして押せる幅を確保し、右下40×40pxの専用段より縦の領域を詰める。画像140×187px・タイトル17pxは維持。サンプルだけの変更で、採用は未確定。

最新の小型比較案は、画像・タイトル・操作の3段構成。画像を中央に置き、タイトル17px最大3行の下へ専用の操作段を設け、右下に「⋯」40×40pxを配置する。小型のメニューはボタンの上へ展開する仮動作。画像横の細いボタン案を置き換え、製品への採用は未確定。

小型は画像を枠の中央へ戻し、右上の「⋮」だけ18×40pxに細くした最新の比較案。左右対称の画像領域を確保し、幅が足りない場合は画像枠の横幅を抑えて重なりを防ぐ。通常幅1024pxの5列では約140×187px。細いボタンは押せる横幅が狭くなるトレードオフがあり、採用は未確定。

小型だけ操作ボタンを縦の「⋮」（28×40px）へ変更し、画像の右側に独立した列を確保した。外側の余白を詰め、通常幅1024pxの5列で画像140×187pxを維持する案。タイトルは下段で枠幅を使う。狭い列は画像の横幅を利用可能幅へ収め、操作ボタンと重ねない。行一覧・カードの「⋯」40×40pxは維持。

各作品の「⋯」操作ボタンは40×40pxへ拡大した確認案。行一覧の操作列を8%へ広げ、カードのタイトル右側の余白も調整する。表示切替・登録・ページ切替のボタンサイズは今回変更していない。

小型・カードもマウスオーバー・枠内のキーボードフォーカス中に、作品の枠全体を青灰色（#d5e4f0）で強調する確認案。画像そのものの色は変えず、枠全体を起動リンクにも変更しない。

行一覧はマウスオーバー・行内のキーボードフォーカス中に、交互背景より濃い青灰色（#d5e4f0）で行全体を強調する確認案。行の選択状態やクリックでページを開く動作は追加しない。

利用者は小型5件表示・画像140×187px・タイトル17px最大3行を一旦良好と回答。行一覧は隣の行との区別を付けるため、白と薄い青灰色（#edf3f8）の交互背景を付けた確認用の案とする。製品画面は未変更。

5件表示だけ画像枠を140×187pxへ拡大した比較案。タイトル17px・最大3行は維持する。6件・4件表示の画像枠は120×160pxのまま。画像拡大分だけ5件表示のカード全体は縦に長くなる。製品への採用は未確定。

タイトルは3形式とも17px。小型は最大3行72px、画像枠を120×160pxに小さくした比較案。自動列数ではなく通常幅の列数を明示し、`index.html?compareColumns=1`で同じ幅1024pxの横6件・5件・4件を実寸比較する。単独は`?mode=compact&columns=6`等を指定し、未指定時は5列。狭い幅700px以下は2列とする仮動作。カードのタイトルは2行48px、画像100×134px、高さ164pxを維持。寸法・文字サイズ・列数とも製品仕様としては未確定。

利用者の要望に応じ、一覧上部を詰めた比較案に変更した。枠内に説明帯や大見出しを置かず、通常幅・狭い幅とも件数・表示切替・登録を1行目、検索を2行目にする。通知がない通常状態のサンプルであり、必要時の結果・警告を省略する製品判断ではない。

架空60作品を使い、小型24件・行一覧20件・カード12件を1ページに表示する仮案を試せる。一覧の上下に前へ・ページ番号・次へを置く。検索と形式切替で1ページ目へ戻し、ページ操作で上部へスクロールするのはサンプル用の仮動作で、製品仕様としては未承認。ページ切替は#44の後に別Issue・PRで実装する合意であり、#44の範囲へ混ぜない。件数・登録/削除時の移動・形式切替時の位置・検索時の移動・ページ状態の保持・多数ページの番号省略は別途具体化する。

`index.html`をブラウザーで開く。`index.html?compare=1`では通常幅1024pxと狭い幅520pxを70%に縮小して3形式を並べる。各枠は縦スクロールできる。単独表示では形式切替・タイトルの部分一致検索・「⋯」の展開を試せる。

合成タイトル、example.comのURL、SVGの仮画像だけを使用する。保存・Wails API・外部ページ起動・編集・削除・画像管理は接続せず、ボタンを押しても実行しない。通知帯は合成例であり、実処理の引継ぎを検証したものではない。依存パッケージ・ネットワーク・利用者データは不要。

小型120×160px、カード2列/1列、行一覧の最小幅850px等は比較用の仮寸法であり、利用者確認前に製品仕様へ確定しない。以前の小型最小列幅170pxの自動配置では広い幅で6列になり得たため、列数比較には使わない。メニューや仮画像の操作はラフな例であり、製品のメニューのフォーカス制御、切替中の処理結果と警告、一覧内スクロールとメニューの重なり、標準title、WebView2、設定保持のテストを代替しない。
