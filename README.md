# Manga Update Manager

登録した漫画を表紙付きで一覧表示し、更新予定や最終アクセス日時を管理するローカルデスクトップアプリです。

## 基本方針

- 利用者の漫画一覧、閲覧履歴、画像キャッシュは端末内だけに保存する
- 公開リポジトリにはソースコードと仕様だけを置く
- 自動取得は、利用規約上問題のない公開情報に限定する
- 自動取得できない作品は、更新予定と最終アクセス日時から「要確認」を表示する
- アプリから作品を開いた日時を記録する

## 想定技術

- デスクトップ基盤: Tauri
- バックエンド: Rust
- 画面: TypeScript / HTML / CSS
- ローカルデータ: SQLite
- 対象OS: Windowsを優先

## 最初の実装範囲

1. 作品の登録・編集・削除
2. 表紙カード形式の一覧
3. 既定ブラウザーで作品ページを開く
4. 最終アクセス日時と要確認期間の管理
5. 定期更新情報の手入力
6. 起動時・手動・指定時刻の状態確認
7. 保持データの表形式表示
8. バックアップと復元

サイトからの自動取得は、この基本機能が安定してからサイト単位で追加します。

## 開発状況

設計開始段階です。RustとTauriの開発環境を準備した後、アプリの雛形を生成します。
