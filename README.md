# Manga Update Manager

登録した漫画を表紙付きで一覧表示し、更新予定や最終アクセス日時を管理するローカルデスクトップアプリです。

## 基本方針

- 利用者の漫画一覧、閲覧履歴、画像キャッシュは端末内だけに保存する
- 公開リポジトリにはソースコードと仕様だけを置く
- 自動取得は、利用規約上問題のない公開情報に限定する
- 自動取得できない作品は、更新予定と最終アクセス日時から「要確認」を表示する
- アプリから作品を開いた日時を記録する

## 想定技術

- デスクトップ基盤: Wails v2
- バックエンド: Go
- 画面: React / TypeScript / HTML / CSS
- ローカルデータ: SQLite（`modernc.org/sqlite`＋`database/sql`）
- 対象OS: Windowsを優先

## 最初の実装範囲

1. 作品の登録・編集・削除
2. 表紙カード形式の一覧
3. 既定ブラウザーで作品ページを開く
4. 最終アクセス日時と要確認期間の管理
5. 定期更新情報の手入力
6. 起動時・手動・指定時刻の状態確認
7. 保持データの表形式表示
8. バックアップと復元

サイトからの自動取得は、この基本機能が安定してからサイト単位で追加します。

## 開発状況

Go＋Wails v2とReact＋TypeScriptのアプリ雛形、および作品モデルとSQLite保存基盤を実装しました。画面からの作品登録と一覧表示は後続の開発工程で追加します。

## 開発コマンド

必要な環境はGo、Node.js、npm、Wails CLI v2.14.0、WebView2です。

```powershell
wails doctor
wails dev
```

検証には次のコマンドを使用します。

```powershell
go test ./...
npm --prefix frontend run build
wails build
```

## 開発運用

- GitHub Issuesを唯一の作業管理手段とする
- GitHub Flowで短命な作業ブランチとPRを使用する
- 重要な設計判断はADRへ記録する
- Issueに目的と受け入れ条件を記載する
- テスト、静的解析、ビルド、手動確認の結果をPRへ記録する
- 個人データと秘密情報が含まれていないことをマージ前に確認する
