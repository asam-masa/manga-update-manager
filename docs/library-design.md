# 作品一覧の拡張設計

2026-10-09までのgrillingで合意した機能の振る舞いを記録する。**この文書の機能は未実装**である。現在の実装は[作品登録と一覧画面](./work-screen.md)を参照する。

重要な判断の背景と選択肢は[ADR-0005](./adr/0005-define-library-behavior.md)へ分離する。作業状態と受け入れ条件はGitHub Issuesで管理し、この文書へ進捗を重複記録しない。

## ページ起動と最終アクセス

- アプリから登録URLそのものを既定ブラウザーへ渡す。最新話や第1話のURLを推測・自動取得しない。
- 最終アクセスは、ブラウザーへの起動要求が正常に渡った時刻を意味する。ページの表示完了や読了は確認しない。アプリ以外からのアクセスは記録しない。
- 起動要求の失敗時は日時を変更しない。
- 起動要求成功後にDB保存が失敗した場合、ページを開いたまま「ページを開きましたが、最終アクセス日時を保存できませんでした」と案内する。画面の日時は保存済み値を維持する。
- 一度も開いていない作品と既存作品は未設定として扱い、「未アクセス」と表示する。登録日時から補完しない。
- 同じ作品の処理中は連続起動を防ぐ。操作はキーボードにも対応する。
- 保存はUTC、表示と予定の日付基準はAsia/Tokyoを維持する。

## 表示形式と操作箇所

| 形式 | 情報 | 開く操作 |
| --- | --- | --- |
| 小型表示 | 画像・タイトルだけ | 画像 |
| 画像なしの行一覧 | タイトル・URL・最終アクセス。更新予定機能で次回更新予定列を追加する | URL |
| メモなしカード | 画像・タイトル・サイト名・URL・最終アクセス | URL |

作品名は全形式で通常の文字列として選択・コピーできる。開く操作は一作品に一か所とする。画像は利用者が用意したものを表示する。画像管理を実装するまで仮表示を使用する。

同じ表示形式では、作品ごとにカード・行の寸法が変わらないようにする。メモなしカードのタイトルは最大2行、URL・サイト名・日時は1行とする。短い情報や未入力の項目にも枠を確保する。メモは上記3形式では表示しない。

URLは1行で省略し、押すと省略前の登録URLを開く。全文確認はWebView2標準の`title`属性で行い、独自ツールチップは作らない。標準機能の表示位置・待ち時間をアプリが制御できるとは扱わず、キーボードでの全文表示も保証しない。

固定寸法は同じ形式・同じウィンドウ幅での均一性を意味する。実際の寸法、列数、狭い画面での配置、画像の収め方、タイトル全文を確認する方法は着手前に決める。添付された参考画像の話数・更新時刻・閲覧数などは、要望として採用していない。

## 登録フォームと検索

画面上部の「作品を登録」ボタンでフォームを開閉する。隠したときは一覧の領域を広げる。途中の入力はアプリ終了まで保持する。登録成功時の入力クリアは既存動作を維持する。

漫画名検索は、入力に応じてタイトルの部分一致で絞り込む。空欄なら全作品が対象となる。表示形式を切り替えても検索条件を維持する。検索の大小文字・全半角・かな・空白の扱いは未決定である。

## 並び順と更新予定

行一覧へ「次回更新予定」の列を追加する。見出し操作では、通常の日付昇順ではなく次の今日優先順で並べる。一覧を左右の独立領域に分割しない。

1. 今日の予定
2. 過去の予定: 昨日、一昨日…の順
3. 未来の予定がONなら、明日、明後日…の順
4. 予定未設定の作品

未来の予定はON/OFFで表示対象に含めるか切り替える。予定未設定はON/OFFにかかわらず末尾に残す。今日の基準はAsia/Tokyoとする。

登録順・タイトル順・最終アクセス順と昇降順は**候補であり未確定**である。予定順での同日作品の順序、未アクセス作品の位置、未来ON/OFFを他の並び順にも適用するか、並び順と未来ON/OFFの初期値も着手前に決める。

更新予定を入力・計算する規則は未決定である。過去予定の保持、次回への繰り越し、繰り返し、月末、休止、複数予定、日付変化・スリープ復帰時の扱いを今回の並び方だけから確定しない。

## タグ

- 一作品に複数タグを付けられる。階層は持たない。
- タグ入力では既存タグを候補表示し、入力文字で候補を絞り込む。選択して再利用する。
- 新規タグは「新しいタグを作成」を明示的に選んだときだけ作る。入力だけで自動作成しない。
- 名前の前後の空白を除き、完全一致の重複を禁止する。既存名への名前変更は止める。大文字小文字や全半角などの同一視は承認していない。
- 複数タグの選択はAND条件とする。タグ未選択ならタグ条件で制限しない。漫画名検索もある場合は両条件を満たす作品を表示する。
- タグ名変更は関連する全作品へ反映する。タグ削除は関連だけを外し、作品を削除しない。
- タグ統合は初回の対象外とし、必要になった時点で別Issueへ分ける。

タグのDB/API、付け外し・管理UI、空名や長さ制限、候補の一致方法、未使用タグ、削除後の選択状態は着手前に検討する。

## 設定の保持

| 状態 | 再起動後 |
| --- | --- |
| 表示形式・並び順・未来の予定ON/OFF・登録フォーム開閉 | 保存した設定を復元する |
| 検索文字・選択タグ | 解除する |
| 登録フォームの途中入力 | 保持しない |

初回起動はメモなしカード・登録フォーム表示とする。対象の表示形式が未実装の段階では選択肢へ先行追加せず、形式の追加時に初期状態を反映する。

検索文字・選択タグの再起動後の保持は将来追加できるよう、一覧の表示条件と保存対象を分ける。将来用の保存機能まで先に実装しない。保存場所・形式・破損・読み書き失敗時の動作は未決定である。
