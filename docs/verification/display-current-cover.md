# 既存カードの画像表示

Issue #165。正本は[画面設計](../work-screen.md)と[画像保存・配信契約](../cover-persistence.md)。画像設定・解除ボタンは未実装である。

## 表示契約

起動時整理の`LoadCoverWarnings`が成功応答を返してから画像取得を許可する。整理失敗の警告を含む応答でも、処理と解放は終了している。API自体が拒否された場合は画像を取得せず、既存の画面上部の再起動案内を残す。警告を閉じる操作と画像取得の可否は分ける。

画像参照が非空なら作品IDだけの`/__covers/works/<id>`を使い、管理パスをURLへ埋め込まない。既存の56×76px、400px以下では40×56pxの枠を保ち、object-fit: scale-downで全体を収める。読み込み中と未設定は「本」の仮表示、失敗時は同じ仮表示と当該カード内だけの「画像を表示できません」を表示する。画像は装飾扱いでリンクを付けず、作品URLとタイトルコピーの契約を変えない。

一覧の再読み込みが成功したときだけ画像表示の世代を更新し、画像要素と失敗状態を作り直す。検索やURL起動だけでは同じカードの世代を変えない。参照変更でも新しい表示を作る。画像失敗を理由にDB参照を変更しない。
