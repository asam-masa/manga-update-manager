# バックアップ画面の初期接続

2026-11-18、#608で保存先・保全候補の表示を追加した。完了した実行IDでのみ専用APIを呼び、応答ID・公開状態・候補種別を検証する。別実行やアンマウント後の応答を採用せず、取得失敗は結果概要を保持して場所だけ再読み込みできる。選択先・確認済み場所・候補を区別し、空の記録や候補なしを保存成功・不存在へ読み替えない。開く・削除・再保存の操作は追加していない。

場所表示の単体18件と既存試験を含む571件、型確認/製品ビルドが成功した。合成APIのPlaywright操作・配置17件では、通常幅の確認済み場所、幅390pxの長いパスと4種類の保全候補、詳細取得失敗からの再取得を確認した。詳細の再取得では開始APIを再送しない。Codexは通常幅と狭い幅の撮影画像を確認した。`--ignore-snapshots`の結果であり、画像比較の成功とは扱わない。既存の一覧基準画像・比較条件は変更していない。

以下の#606時点で対象外とした保存先/保全候補は、この追加で接続済みである。除外画像/作品名の詳細・実Wailsの追加確認・復元は引き続き後続とし、ADR-0022はPendingを維持する。

Issue #606。2026-11-18、作品一覧の「タグ管理」の隣に入口を追加し、開始・取消・再取得と結果概要を既存のセッション部品へ接続する。保存先/残置候補・除外画像と作品名の詳細画面、復元は対象外である。

## 接続と操作

セッションはAppが所有し、ダイアログを閉じても処理・保持結果を捨てない。画面再読込後は状況を取り直し、進行中の処理があればダイアログを開く。初期接続で新しい保存を自動送信しない。保存先選択・取消要求・応答後の再観測中は閉じずに待つ。背景の通常操作と複数ダイアログは既存のmodal判定と標準dialogで防ぐ。

閉じると入口へフォーカスを戻し、警告付き結果は一覧にも残す。通常操作の再開やDBの安全性を、画面のretryAllowedから推測しない。取消ボタンなどが状態変更で消えてフォーカスがbodyへ外れた場合は、ダイアログ内の見出しへ戻す。

## 確認した範囲

- App結合単体試験で保存・結果保持・一覧の警告・入口へのフォーカス復帰・進行中の初回再接続・別dialogの拒否を確認した。
- 合成APIを使うPlaywrightで、保存・選択取消・Esc・再表示・警告保持、画面再読込からの進行中再接続・取消後の片付け待ち、幅390pxの結果不明・再保存停止を確認した。
- `--ignore-snapshots`の16試験は操作・配置の成功であり、基準画像との比較成功ではない。Codexは通常幅の結果概要と狭い幅の結果不明を撮影画像で確認した。
- 入口追加で既存の一覧基準画像に意図した差分が出た。ローカルの代表compact 1200pxは1125pixelの不一致で、入口/検索欄の変化と既知の字体差を目視確認した。ローカルの画像を基準には使用していない。
- [CI 44303222136](https://github.com/asam-masa/manga-update-manager/actions/runs/44303222136)（対象head `73957e0871c5a6f624d9ca01b733350b44e04480`、Windows 10.0.26100・Node.js 24.22.2・Chromium 159.0.8154.6）では操作30件が成功し、6画面×3回の画像比較18件だけが不一致だった。Codexは6画面の画像と差分を確認し、通常幅は入口/検索欄、狭い幅はその折返しに伴う51pxの縦移動であることを確認した。各画面3回のSHA-256一致を確認して、このCI撮影画像で6基準を更新した。閾値・比較範囲は変更していない。更新後のCI結果は[PR #607](https://github.com/asam-masa/manga-update-manager/pull/607)に記録する。

## 残る確認

この工程は合成APIのブラウザー検証であり、製品Appから実Wailsへ接続した保存先選択・実保存・終了案内を確認した結果ではない。既存の[API単体の実Wails記録](./backup-wails-api.md)と区別する。保存先/残置候補・除外詳細、全異常系、復元も後続に残し、ADR-0022はPendingを維持する。
