# バックアップ画面のサンプル確認

Issue #541。2026-11-16、合成データだけのHTMLサンプルで配置と詳細表示を確認し、利用者が次の案を承認した。製品画面・公開API・実保存は変更していない。

## 合意した配置

- 作品一覧の「タグ管理」の隣に「バックアップ」ボタンを置く。
- 画面中央のダイアログに表示する。見出しと下部ボタンを固定し、長い本文だけをスクロールする。狭い幅では余白とボタン配置を調整する。
- 開始前は保存対象と、暗号化なし・非上書き・通常操作の一時停止を案内する。保存先を選ぶ主操作と閉じる操作を下部に置く。
- 処理中は段階と経過時間を表示し、取消後は片付けの完了を待つ。保存確定前までの取消可否は既存APIに従う。サンプルの段階・時間は合成値で、実行や進捗を示さない。
- 結果は保存できた事実と注意事項を分け、保存先と除外件数を表示する。結果不明は成功と扱わず、保全候補を示す。解放未確認でも公開確認済みの事実を消さない。既存の再実行制約は変更しない。

## 除外詳細の移動

結果概要から除外画像一覧を開き、画像を選ぶと、その画像を使う作品一覧へ同じダイアログ内で切り替える。別ダイアログは重ねない。以前の「画像ごとの作品名をその場で展開する」表示候補を、この方式で具体化した。

画像・作品ともAPIに合わせて1ページ50件とし、前へ・次へで切り替える。画像件数と作品件数は混同しない。作品一覧から戻ると元の画像一覧のページ・スクロール位置を保ち、選択した画像の操作ボタンへフォーカスを戻す。結果へ戻る場合は詳細を開いた操作へ戻す。

詳細の取得に失敗しても保存結果の概要は残し、詳細欄だけにエラーと再読み込み・戻る操作を表示する。自動で概要へ追い返さず、バックアップも自動でやり直さない。未知・利用不可の件数を0件と扱わない既存APIの条件は維持する。

## サンプルと確認方法

`build/bin/541-backup-sample.html`と詳細表示用の合成スクリプトを使用した。実API、ファイル操作、外部通信はなく、ボタンの遷移や取得失敗もサンプル内の表示切替である。一時サンプル・撮影画像・撮影スクリプトはGitへ追加しない。サンプルは正本や製品へ流用する完成部品ではない。

| 確認 | 方法と結果 |
| --- | --- |
| 基本配置 | 開始前と警告付き結果の撮影画像を利用者が確認し、入口・中央ダイアログ・固定見出し/下部ボタンを承認 |
| 詳細配置 | 作品一覧と狭い幅の取得失敗画像を利用者が確認し、概要保持と同じダイアログ内の切替を承認 |
| 通常幅・狭い幅 | Chromium/Playwrightで幅1100px・390pxを撮影。ページ全体の横はみ出しがないことを確認 |
| ページ境界 | 合成52画像と、選択画像を使う合成103作品で、50件・画像末尾2件・作品末尾3件を確認 |
| 戻る操作 | 画像一覧2ページ目の画像51から作品一覧へ移動し、戻ると画像一覧2ページ目と画像51の操作フォーカスが保たれることを確認 |
| 取得失敗と再取得 | 合成失敗を表示しても保存済みの概要を維持。再読み込み後に作品一覧50件を表示。通常幅・狭い幅とも確認 |
| スクリプト | 上記の代表操作でJavaScriptエラーがないことを確認 |

スクロール位置の保持は合意済みだが、上記の自動アサーションはページとフォーカスの復元を対象とし、全位置のスクロール復元を測定したものではない。撮影画像の目視はCodexと利用者による確認で、製品の画像比較テストの基準画像にはしていない。

## 後続と限界

2026-11-18、#602で開始前・処理中・結果概要を`BackupDialog`のReact部品へ移した。検証済み状況・結果と、選択中/取消要求中の状態をpropsで受け、開始・取消・再読み込み・閉じるを呼出し元へ通知する。取得未確認や別実行の結果から再開始せず、処理中/選択中は閉じる操作を止める。取得やコマンドの寿命・二重送信防止は、後続のApp/API接続側の責務とする。

部品の16単体試験で、表示・実行ID対応・取消/再開始/終了の有効条件・Escを確認した。一時ハーネスから実React部品をChromium/Playwrightで表示し、幅1100px・390pxの開始前/長い警告付き結果を撮影した。横はみ出しなし、結果本文のスクロール、スクロール前後で下部ボタンの位置が変わらないこと、見出しへの初期フォーカス、Escの通知、JavaScriptエラーなしを確認した。Codexは通常幅の開始前と狭い幅のスクロール後を目視確認した。一時ハーネスと撮影画像はGitへ追加せず、基準画像との比較やCIに常設した試験とは扱わない。

この段階ではAppの入口・実API・場所/除外詳細ページ・一覧側の警告保持へは未接続であり、製品画面の利用開始や実保存を検証したものではない。

#542では、承認済み配置を既存React画面とAPIへ接続し、必要なら小さなPRへ分割する。背景操作の遮断、Tab/Shift+Tabのフォーカス制御、Esc、閉じた後の入口への復帰、状況取得失敗/再接続、実行IDの切替、警告通知の一覧側保持は製品の状態管理と合わせて検証する。今回のサンプルから、それらの実装完了や製品の安全性を推定しない。

Windows標準保存ダイアログと実保存は[#590/#591の実Wails検証](./backup-wails-api.md)へ分ける。今回のブラウザー確認は代替ではない。製品画面・復元は未実装で、ADR-0022はPendingを維持する。正本は[バックアップ設計](../backup-restore.md)、[公開API](../backup-api.md)、[ADR-0022](../adr/0022-manual-backup-and-replacement-restore.md)とする。
