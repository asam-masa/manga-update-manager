# 公開リポジトリ監査

初回公開前と、公開範囲へ大きな変更を加える前に確認します。

## Git履歴

- [ ] コミットに個人用メールアドレスを含めない
- [ ] 過去のコミットに秘密情報や個人情報がない
- [ ] 意図しない大容量ファイルやバイナリがない

## 利用者データ

- [ ] 漫画一覧、閲覧履歴、ブックマークファイルがない
- [ ] 表紙画像と画像キャッシュがない
- [ ] SQLiteデータベースとバックアップデータがない
- [ ] ログとスクリーンショットに個人情報がない

## 秘密情報

- [ ] Cookie、パスワード、トークン、秘密鍵がない
- [ ] `.env`などのローカル設定がない
- [ ] GitHub Actionsの権限が必要最小限である

## 法務・外部サービス

- [ ] リポジトリのライセンス方針が確定している
- [ ] 外部依存関係のライセンスを確認している
- [ ] 表紙画像、漫画本文、サイトロゴを配布物へ同梱していない
- [ ] 自動取得対象の利用規約と公開仕様を記録している

## 文書とビルド

- [ ] README、CONTRIBUTING、SECURITYが現在の実装と一致する
- [ ] クリーンな環境からビルドとテストを再現できる
- [ ] 生成物の管理方針が記録されている
- [ ] 未確定事項を確定済みとして記載していない
