# 要件

## 目的

漫画ごとのブックマークを一つずつ開かなくても、確認が必要な作品を一画面で判断できるようにする。

## 必須機能

- アプリ起動時に作品の状態を確認する
- 任意のタイミングで確認ボタンを押せる
- 設定時刻にアプリが起動していれば自動確認する
- URL、タイトル、表紙画像、定期更新情報を手入力できる
- 許可され、技術的に取得可能な情報は自動入力・自動確認できる
- 自動確認できない作品は、最後に開いてから1週間・2週間・1か月などの期間で「要確認」にする
- 作品を選ぶと既定ブラウザーでURLを開く
- 保持しているデータを表形式でも閲覧・編集できる

## 一覧拡張の合意事項

登録フォームの開閉、漫画名検索、三つの表示形式、タグ付け・絞り込み、表示設定の保持、今日を優先する予定順を合意した。振る舞いと未決定事項の正本は[作品一覧の拡張設計](./library-design.md)、重要な判断の背景は[ADR-0005](./adr/0005-define-library-behavior.md)を参照する。これらを実装済みとは扱わない。

## 状態

- 更新あり
- 更新予定
- 確認済み
- 要確認
- 取得失敗
- 手動管理
- 休止中

## 非目標（初期版）

- あらゆる漫画サイトへの汎用スクレイピング
- ログイン制限やアクセス制限の回避
- 漫画本文、有料画像、認証情報の保存
- アプリ終了中の常駐確認
