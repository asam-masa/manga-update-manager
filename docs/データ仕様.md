# データ仕様（初稿）

## 作品

| 項目 | 用途 |
|---|---|
| ID | アプリ内部の識別子 |
| URL | 作品ページ |
| タイトル | 一覧表示 |
| サムネイル | ローカル画像または参照先 |
| サイト名 | 絞り込みと表示 |
| 管理方法 | 自動取得・予定管理・最終アクセス管理 |
| 最新話 | 取得値または手入力値 |
| 前回の最新話 | 更新判定 |
| 最終アクセス日時 | 要確認判定 |
| 最終確認日時 | 状態確認の記録 |
| 定期更新ルール | 毎週・隔週・毎月・任意日など |
| 次回更新予定 | 一覧表示と確認タイミング |
| 未アクセス警告期間 | 1週間・2週間・1か月など |
| 状態 | 更新あり・要確認など |
| メモ | 利用者の自由記入 |

## 保存境界

利用者データと画像キャッシュはOSが提供するアプリデータ領域へ保存し、Gitリポジトリ内には作成しない。
