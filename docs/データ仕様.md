# データ仕様（初稿）

## 作品

| 項目 | 用途 |
|---|---|
| ID | アプリ内部の識別子 |
| URL | 作品ページ |
| タイトル | 一覧表示 |
| サムネイル | ローカル画像または参照先 |
| サイト名 | 絞り込みと表示 |
| 管理方法 | 自動取得・予定管理・最終アクセス管理 |
| 最新話 | 取得値または手入力値 |
| 前回の最新話 | 更新判定 |
| 最終アクセス日時 | 要確認判定 |
| 最終確認日時 | 状態確認の記録 |
| 定期更新ルール | 毎週・隔週・毎月・任意日など |
| 次回更新予定 | 一覧表示と確認タイミング |
| 未アクセス警告期間 | 1週間・2週間・1か月など |
| 状態 | 更新あり・要確認など |
| メモ | 利用者の自由記入 |

## 保存境界

利用者データと画像キャッシュはOSが提供するアプリデータ領域へ保存し、Gitリポジトリ内には作成しない。

## 初期作品テーブル

最初のSQLiteマイグレーションでは、作品登録の核となる項目だけを保存する。更新状態や日時計算の規則が必要な項目は、規則を実装するIssueでマイグレーションを追加する。

| 列 | SQLite型 | 必須 | 規則 |
| --- | --- | --- | --- |
| `id` | INTEGER | はい | 内部識別子。SQLiteが採番する |
| `url` | TEXT | はい | 前後の空白を除去し、`http`または`https`だけを許可する。完全一致の重複を禁止する |
| `title` | TEXT | はい | 前後の空白を除去し、空文字を禁止する |
| `site_name` | TEXT | はい | 未入力は空文字として保存する |
| `thumbnail_path` | TEXT | はい | 未入力は空文字とする。指定する場合はアプリ管理領域内の相対パスとする |
| `notes` | TEXT | はい | 未入力は空文字として保存する |
| `created_at` | TEXT | はい | UTCのRFC 3339形式で保存する |
| `updated_at` | TEXT | はい | UTCのRFC 3339形式で保存し、`created_at`より前にしない |

## 日時の境界

- 保存する時刻はUTCへ統一する
- 画面表示、利用者入力、更新予定、アラート判定は`Asia/Tokyo`を基準にする
- 日付だけを表す値は、日本時間のカレンダー日付として`YYYY-MM-DD`で保存する
- Windowsのタイムゾーン設定が変わっても、利用者向けの基準時間は日本時間を維持する
